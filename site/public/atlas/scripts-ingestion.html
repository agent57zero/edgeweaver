    Atlas: ingestion scripts

    TLDR

    These scripts move source material into governed memory without confusing a library with lived experience. Fetchers and parsers create inspectable staging files; ingesters attach provenance, audience, license, and stable deduplication keys before any row reaches the Brain. The raw corpus and staging outputs stay outside Git. Protected family material and privately licensed readings are described here only by their permitted shape.

    What this page covers

    This page follows the pipeline from acquisition through parsing to insertion. A downloader may touch an upstream source, a parser turns local bytes into reviewable JSONL, and an ingester writes only after the required human-controlled credential and governance checks exist. Each entry distinguishes what is repeatable from what remains staged, and links the code to the memory and segmentation rules that govern its output.

    File entries

    scripts/fetch-sparks.mjs active-code

    What it is. A polite, repeatable downloader for the English SPARK document archive used by the Possibility Management teaching shelf.
    What it contains. It discovers document names from the upstream index instead of relying on a hand-maintained range, skips local files already present, validates that downloads are plausible, throttles requests, and reports failures without hiding partial success.
    Who reads it and when. An operator runs it during corpus preparation, before parsing. The being never reads this network utility and the downloaded corpus remains outside Git.
    How to verify or reproduce it. Run it only when refreshing the licensed source set, inspect its counts and failure list, then let the parser's own summary expose malformed or partial documents. Re-running should skip completed downloads.
    Related concepts. See the Brain for the library class and the walls for why source bytes and credentials stay separate.

    scripts/filter-edgeweaver-convos.mjs active-code

    What it is. The Phase 0a import filter that selects Edgeweaver-related records from a user-supplied conversation export before pre-birth ingestion.
    What it contains. Its pure filter accepts approved custom-assistant identifiers and title patterns, keeps matches from either route, and returns kept, dropped, and total counts. The command-line wrapper reads an export and may write the selected subset.
    Who reads it and when. Alan supplies the real selectors during the blocked Phase 0a/G3 work. An operator reviews the resulting count before any selected conversation can become memory.
    How to verify or reproduce it. The hermetic import-filter verify uses invented conversations to prove both selector routes and the dropped count. Real titles, identifiers, export contents, and selected conversation text are never published here.
    Related concepts. See Genesis status, memory provenance, and the disclosure boundary.

    scripts/ingest-library.mjs active-code

    What it is. The governed inserter for two teaching shelves: Possibility Management distinctions and the separately licensed coherence readings. These rows are library material, not episodes.
    What it contains. It loads reviewed staging JSONL, selects either shelf or both, applies a caller-supplied limit, and writes bounded content plus source type, audience, attribution, license, and stable metadata keys. It checks those keys before insertion, pauses between writes, and can fall back to metadata when an older database lacks a dedicated source-type column. A missing service credential stops the run instead of improvising access.
    Who reads it and when. An operator uses it after parsing and rights review, with Alan controlling the privileged credential. Study and analysis consumers may later read allowed library rows, while episodic recall must exclude them.
    How to verify or reproduce it. Compare parser row counts with inserted and skipped totals, sample the stored provenance fields, complete the embedding backfill, and run recall-scoping checks. Repeating the same input should add no duplicates. The script's final message points to retrieval verification rather than treating insertion as success by itself.
    Related concepts. The governing model is on the Brain page; recall-scoped enforces consumer walls, and growth explains the study shelf.

    scripts/ingest-prebirth-harvest.mjs described-not-shown

    What it is. A protected importer that can make governed pre-birth source material recallable as parent-scoped episodes.
    What it contains. It reads named soul-source documents, creates governed units, adds pre-birth provenance and stable keys, then requests embeddings. Protected text and structure are not repeated here.
    Who reads it and when. An Alan-present operator uses it before First Boot.
    How to verify or reproduce it. Privately check counts, audience, stable keys, and repeat-run skips without copying content.
    Related concepts. See the Soul, the Brain, and what is withheld.

    scripts/ingest-sparks.mjs active-code

    What it is. The inserter that turns reviewed SPARK staging rows into a structured Possibility Management teaching shelf inside OB1.
    What it contains. For each source document it writes a parent teaching row and separate experiment children, all carrying public audience, license, attribution, parse status, and matrix identifiers. Child-to-parent derivation edges are attempted when the graph table exists. Stable matrix keys make the operation idempotent. The script tolerates an older source-type layout through an explicit fallback, but it refuses to proceed without both the database location and Alan-controlled service credential.
    Who reads it and when. An operator runs it after download, parsing, and source review. The study loop may read allowlisted teachings; ordinary episodic recall may not treat them as lived experience.
    How to verify or reproduce it. Start with a small limit, compare parent and child counts, inspect provenance and derivation on samples, and repeat to confirm skips. A missing optional graph table is reported rather than disguised. Finish with embedding and retrieval-scoping checks, since rows that cannot be searched safely are not a complete ingestion.
    Related concepts. See the study practice, provenance classes, and the study loop entry.

    scripts/parse-coherence-book.py described-not-shown

    What it is. A local parser for privately licensed coherence readings supplied for this project.
    What it contains. It recognizes structural boundaries, creates parent and section records, attaches attribution, audience, license, and parse-status metadata, and writes staging JSONL. The reading's substance is not reproduced here.
    Who reads it and when. An operator uses it during a rights-aware corpus refresh; only governed library consumers read the resulting shelf.
    How to verify or reproduce it. Privately review boundaries and metadata, then compare parser and ingestion counts. Never publish passages as evidence.
    Related concepts. See coherence and library provenance.

    scripts/parse-distinctionary.py active-code

    What it is. The parser that converts a locally captured Possibility Management Distinctionary source into one reviewable JSONL record per term.
    What it contains. It recognizes linked and plain term forms, joins continuation paragraphs, removes navigation noise while retaining useful cross-references, and writes provenance fields needed by the library ingester. Conservative pattern checks keep ordinary page sentences from becoming false entries.
    Who reads it and when. An operator runs it after obtaining the source under its applicable terms. Reviewers inspect the staging file before privileged insertion; the being encounters only governed teaching rows later.
    How to verify or reproduce it. Compare parsed counts and a sample of term boundaries with the local source, inspect rejected or suspicious lines, and confirm each output record carries license and attribution. Re-run from the same bytes for deterministic output.
    Related concepts. See teaching and distinctions, the library shelf, and the library ingester.

    scripts/parse-sparks.py active-code

    What it is. The offline parser that turns downloaded SPARK documents into structured teaching and experiment staging records.
    What it contains. It extracts a document identifier, distinction, notes, and numbered experiments, removes repeated footer noise, and records a visible parse status when expected markers are incomplete. It never silently drops a partial parse. Its output is JSONL plus a human-readable summary.
    Who reads it and when. An operator runs it after the downloader and reviews the summary before ingestion. Later consumers see only governed rows, not the parsing workspace.
    How to verify or reproduce it. Use the pinned sample check and summary counts, inspect every partial-status row, and ensure matrix identifiers and experiment grouping remain stable. Parsing the same corpus again should produce the same logical records.
    Related concepts. See the curriculum, provenance, and the SPARK ingester.
