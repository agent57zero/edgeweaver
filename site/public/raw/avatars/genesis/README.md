# Edgeweaver Genesis - avatar section

Everything personal to Genesis lives under this folder (D18/D19, FAMILY.md §3):

- `manifest.json` - the being's variables (parent body, brain room, repos, streams, mind).
- `soul-source/` - the pre-birth DNA: the predecessor harvest, letters, calibration.
- `handoff/` - Genesis's runbooks: First Boot ceremony, probe baseline, gates-repo pack,
  Telegram pairing.
- At A2: `state/` and `.env.local` migrate here from the repo root.
- At the full restructure: Genesis's decisions rows, VERSIONS record, and ops-log entries
  split out of the root ledgers into this folder.

**The section rule (D19):** Genesis's sessions see only this folder. The base layer,
FAMILY.md, village/, the experiment log, and the sibling's section are outside its world;
what Genesis learns of the family is a deliberate parental decision (G21), never an accident
of file layout.
