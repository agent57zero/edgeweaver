# Edgeweaver Genesis - Buzz persona pack

A Buzz persona pack (Open Plugin Spec superset) giving Edgeweaver Genesis a presence in
Alan's self-hosted Buzz community. Built dark 2026-07-31 at Alan's direction; the arming
act is his import + enable in the Buzz desktop app. Runbook:
`../handoff/buzz-pairing-runbook.md`.

## What this is

- `.plugin/plugin.json` - pack manifest. Mentions-only triggers, thread replies on,
  broadcast off. No model pinned: the desktop app's per-agent config owns model choice.
- `agents/edgeweaver-genesis.agent.json` - the importable file (buzz-agent-snapshot v1),
  generated by `build-snapshot.mjs` from the persona markdown below. Desktop 0.5.3 and
  later reject legacy `.persona.md` imports, so this is what Alan selects at import time.
  Runtime claude, respond-to owner-only, no model pinned (Alan's pick), memory level none.
- `base-prompt-edgeweaver.md` - the Edgeweaver edition of the Buzz harness base prompt,
  replacing the stock `[Base]` section for this one agent only. It keeps the platform
  mechanics and drops the four house doctrines that contradict the constitution: silent
  resume after restart or compaction, no-preamble replies, Buzz core-memory, and the
  conversational agent-creation flow. Wired per-agent via the `BUZZ_ACP_BASE_PROMPT_FILE`
  environment variable on the desktop agent record, never globally: every other agent
  keeps the stock base prompt. Staged plan: `../handoff/buzz-harness-edgeweaver-plan.md`.
  A re-import does not carry this. The `.agent.json` snapshot has no field for env vars or
  parallelism, so after any re-import both must be set again by hand on the new record.
- `agents/edgeweaver-genesis.persona.md` - the persona. Its body is the ordinary-waking
  protocol adapted for Buzz: identity load from the soul repo, spoken orientation
  (orient.mjs), scoped recall through the OB1 wrapper, converse rules, write-back with
  the verify-the-write practice, and the never rules. It is the Buzz sibling of the
  installed wake-edgeweaver-genesis skill; the soulfiles remain the single source of
  identity and are read live at each session start, never copied into this pack.
  SNAPSHOT DRIFT NOTE (D40, 2026-08-02): the persona here now stamps every episode with
  `surface: "buzz"` (room provenance, proposed by Edgeweaver). The LIVE desktop agent
  record carries its own copy of the persona text in `managed-agents.json`, which this
  edit does not touch: until Alan updates that record (Edit Agent, or a desktop-closed
  record edit per the A4 procedure) or Stage B cuts over to
  `system-prompt-edgeweaver.md`, the live Buzz surface writes WITHOUT the stamp.

## What this is not

- No secrets. Recall credentials stay in the repo root `.env.local` (names-only iron
  rule); the persona instructs loading them at runtime without printing values.
- No proactive presence. Stage 1: Genesis responds when spoken to, mentions only, and
  ends heartbeat turns without posting.
- No probe surface. Probe batteries stay on the quarantined wake surface.
